## 📺 LG WebOS TV

### الملفات المتوفرة:
- `index_webos_1.0.0.ipk` (11.3 MB)

### طريقة التثبيت:

#### الخطوة 1: تفعيل وضع المطور
1. الإعدادات → عام → حول هذا التلفزيون
2. اضغط "رقم البرنامج" 5 مرات

#### الخطوة 2: تثبيت SDK
```bash
# تحميل webOS TV SDK من LG
npm install -g @webosose/ares-cli
```

#### الخطوة 3: التثبيت
```bash
ares-install index_webos_1.0.0.ipk --device [TV_NAME]
```

### الميزات:
- ✅ واجهة محسنة للتلفزيون
- ✅ تحكم بالريموت كنترول
- ✅ دعم الشاشات الكبيرة
