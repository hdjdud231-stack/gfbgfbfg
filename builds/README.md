# تطبيق Index - ملفات البناء

## الملفات المتوفرة:

### 1. تطبيق الأندرويد (APK)
- `index_android_arm64.apk` - للأجهزة الحديثة (64-bit)
- `index_android_arm32.apk` - للأجهزة القديمة (32-bit)

### 2. تطبيق الويب
- مجلد `index_web/` - يحتوي على جميع ملفات الويب
- يمكن رفعه مباشرة على Netlify أو أي استضافة ويب

### 3. تطبيق iOS
- **متطلبات البناء**: macOS + Xcode + Flutter
- **دليل البناء الكامل**: `IOS_BUILD_GUIDE.md`
- **دليل البناء السريع**: `QUICK_IOS_BUILD.md`
- **سكريبت البناء التلقائي**: `build_ios.sh`
- **ملفات الإعداد**: ExportOptions.plist (App Store، Development، Ad Hoc)

### 4. تطبيق التلفزيون (LG WebOS)
- `index_webos_1.0.0.ipk` - ملف التثبيت للتلفزيون

## طريقة تثبيت تطبيق WebOS على تلفزيون LG:

### الخطوة 1: تفعيل وضع المطور
1. اذهب إلى الإعدادات في التلفزيون
2. اختر "عام" ثم "حول هذا التلفزيون"
3. اضغط على "رقم البرنامج" 5 مرات متتالية لتفعيل وضع المطور

### الخطوة 2: تثبيت أدوات التطوير
1. قم بتحميل وتثبيت webOS TV SDK من موقع LG الرسمي
2. أو استخدم أداة webOS TV CLI

### الخطوة 3: تثبيت التطبيق
```bash
# باستخدام webOS TV CLI
ares-install index_webos_1.0.0.ipk --device [اسم_التلفزيون]

# أو باستخدام webOS TV SDK
# استخدم أداة Device Manager لتثبيت ملف IPK
```

### الخطوة 4: تشغيل التطبيق
1. اذهب إلى قائمة التطبيقات في التلفزيون
2. ابحث عن تطبيق "Index"
3. اضغط عليه لتشغيله

## ميزات التطبيق:

### قسم Index TV (IPTV)
- عرض القنوات التلفزيونية المباشرة
- تصنيف القنوات حسب البلد والفئة
- مشغل فيديو متقدم مع تحكم كامل

### قسم AnimeX
- عرض الأنمي من Anilist API
- تفاصيل كاملة لكل أنمي
- مشغل فيديو مدمج

### ميزات إضافية
- سياسة الخصوصية مدمجة
- رسالة ترحيب عند بدء التشغيل
- تحليلات Amplitude مدمجة
- السيرفر الافتراضي: SuperEmbed

## طريقة بناء تطبيق iOS:

### البناء السريع:
```bash
# تشغيل السكريبت التلقائي
./build_ios.sh
```

### البناء اليدوي:
```bash
# تنظيف وتحديث المشروع
flutter clean && flutter pub get

# تثبيت CocoaPods
cd ios && pod install && cd ..

# البناء
flutter build ios --release

# إنشاء الأرشيف (في Xcode)
# Product → Archive → Distribute App
```

### متطلبات iOS:
- macOS (Big Sur 11.0 أو أحدث)
- Xcode (13.0 أو أحدث)
- Flutter SDK (3.24.5 أو أحدث)
- CocoaPods (1.11.0 أو أحدث)
- شهادة Apple Developer (للتثبيت على الأجهزة)
